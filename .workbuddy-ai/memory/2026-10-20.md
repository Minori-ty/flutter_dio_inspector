## 追加：语言持久化 = 只预留回调，包内不做存储

用户定的方向：「先预留一个配置。如果外部 app 有做 i18n 以及持久化 shared_preferences，
那就有使用者跟着 app 一起配置。如果外部 app 没有，那就不管了，不用持久化。」

即：**包内不引入任何存储依赖，也不自带持久化逻辑**，只留一个口子。

- `PanelLanguageController({initial, onChanged})`：
  - `onChanged` 是 `void Function(PanelLanguage)?`，setter 里**先 notifyListeners 再调它**，
    并用 try/catch + debugPrint 吞掉异常 —— 存盘失败不能把切换卡住（和 interceptor
    「不能影响请求」同一条原则）。
  - 值没变（`value == _language`）直接 return，所以 restore 落到同一个值时不会重复写盘。
- `PanelLanguage.fromCode(String?, {fallback = en})`：容错解析，未知/空/null 都回落，
  启动不抛。写盘方向用内置的 `language.name`，不需要额外 API。
- 刻意**没有** `load` / `restore()`：外部 app 的 prefs 若加载得晚，直接 `controller.language = ...`
  即可，多一个异步 API 只是多一处时序要解释。
- 接入方式（写进 README `#### Saving the choice`）：
  `initial: PanelLanguage.fromCode(prefs.getString('dio_inspector.language'))`
  + `onChanged: (l) => prefs.setString('dio_inspector.language', l.name)`，
  然后把同一个 controller 传给 `DioNetworkPanel(languageController: ...)`。
- 新增 `test/i18n_test.dart`（6 个用例）：name 往返、未知/空/null 回落、默认 en、initial 生效、
  每次变更回调一次（同值不重复）、回调抛异常时仍 notify 且语言已切换。**127 passed**。
